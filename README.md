# 🙏 Mata Greeting Card

## 📌 About the Project
Mata Greeting Card is a simple and beautiful greeting card website created using HTML and CSS. It is designed to share devotional greetings with an attractive visual layout.

## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- Attractive greeting card design.
- Devotional theme.
- Beautiful colours and styling.
- Simple and user-friendly interface.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
